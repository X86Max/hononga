# Hononga

Hononga is a small experimental instant messaging application built with Python and sockets.

The project was originally created as a learning experiment while exploring the idea of building a simple chat application.

## Features

- TCP client-server communication
- Multiple client connections
- Username support
- Message broadcasting
- Message timestamps
- Multithreading for connected clients

## About the name

"Hononga" means "connection" in Māori.

## Status

This is an old experimental/learning project and is not actively maintained.
